# 暑假工计划

一款用 **Godot 4** 制作的中文像素风人生模拟 / 轻策略游戏。  
你扮演一名即将升学的高中生，在 **60 天暑假**里安排打工、学习、休息和社交，在金钱、能力、健康与人际关系之间做选择，最终走向不同的人生结局。

仓库：[github.com/twilight0521/Summer-Job-Plan](https://github.com/twilight0521/Summer-Job-Plan)  
试玩包：[GitHub Releases](https://github.com/twilight0521/Summer-Job-Plan/releases/latest)（当前 `v0.1.1`）

---

## 游戏简介

这个暑假没有标准答案。你可以：

- 早起去早餐店打工，或在奶茶店练沟通
- 泡图书馆备考，冲会计实习路线
- 和同学逛街、帮街坊忙事，攒口碑与信任
- 也可能会熬夜透支，迎来吐槽式收尾

玩法核心是 **每天做选择 → 立刻看到结果 → 再决定下一步**。一局大约 30–60 分钟，适合短局重开、收集不同结局。

## 怎么玩

### 时间结构

| 结构 | 说明 |
| --- | --- |
| 一局 | 60 天 |
| 阶段 | 4 个阶段，每阶段 15 天；第 15 / 30 / 45 / 60 天有阶段总结 |
| 每天 | 凌晨、早上、下午、晚上 4 个时段 |
| 睡觉 | 推进到下一天；睡得早晚会影响能否上早班 |

### 日常循环

1. 看顶部天数 / 时段，以及左右两侧的状态与属性  
2. 在中间「街区」切换地点（地点有营业时间）  
3. 在「可执行」里选行动：工作、学习、吃饭、社交、购物等  
4. 在底栏选一条短期计划，追踪攒钱、数学或信任；达成阶段目标后，选择把收获化为经验，或分享给身边的人
5. 晚上睡觉进入下一天；阶段末可花经验解锁被动，也可参加考试

新开局会弹出 **主线介绍**；把鼠标移到左侧状态或右侧属性上，可以看到该项的作用说明。顶部还会有简短新手提示。

### 主要资源与属性

**状态（左侧）**

| 项目 | 作用概要 |
| --- | --- |
| 现金 | 购物、部分事件门槛 |
| 体力 | 行动消耗；过低影响效率 |
| 心情 | 影响结果与事件选项 |
| 饥饿 | 越高越饿；饿了行动更耗体力，记得吃饭 |
| 疲劳 | 影响起床、效率与受伤风险 |
| 健康 | 受伤/熬夜会降；过低限制行动 |
| 幸运 / 信任 | 影响机会事件与他人是否愿意帮你 |
| 经验 | 阶段结算时用于解锁被动 |

**能力（右侧）**

学习、数学、体能、沟通、技能、责任感 —— 分别对应升学备考、会计路线、体力活、服务业与人际、高收益技能岗、出勤与家庭事件。

### 可去的地方（示例）

家、早餐店、便利店、奶茶店、图书馆、公园 / 健身房、五金建材店、银行 / 办公楼、商业街等。  
到地点后，可做的事会按营业时间和你的条件灰显或开放；不可用行动仍会列出，并提示原因。

### 几条常见路线

- **打工攒钱**：奶茶店、早餐早班、搬砖 / 仓库、家教……注意睡眠与肌肉度门槛  
- **会计实习**：图书馆学数学 → 阶段末考试 → 银行申请会计助理  
- **口碑人际**：拾金不昧、助人事件、经营 NPC 关系与信任值  
- **隐藏线**：商业街找阿凯打听机会；晚上可能遇到「夜班猫」相关剧情  

结局不设唯一正确答案。常见方向包括：稳稳的暑假、第一桶金、技能起飞、关系优先、小小会计师、街坊口碑、夜班合伙人、暑假过载等。

### 操作提示

- 鼠标点击即可游玩；也可用方向键 / Enter / Esc  
- `E` 或界面「发呆」可消磨一个时段；`R` 休息推进；`S` 手动存档  
- Esc 在无强制弹窗时返回标题；事件 / 阶段总结 / 结局必须做出选择才能关闭

## 从源码运行

1. 安装 **Godot 4.7.x stable**（推荐 4.7.2）  
2. 用 Project Manager 导入本仓库目录  
3. 运行主场景（默认 `scenes/boot/boot.tscn`，窗口 1280×720）

### 自动化测试

```bash
godot --headless --path . --scene tests/test_runner.tscn
```

当前约 **251** 条用例（内容加载、日程、事件、存档、结局、回归与完整 60 天通关）。测试使用独立的 `user://test_saves/`，不会覆盖玩家存档。通过退出码 0，失败非 0。

### 目录结构

```text
data/                    内容 JSON：职业、行动、事件、角色、物品、结局
scenes/                  启动、标题、游戏、设置
scripts/app/             流程协调、输入、新手引导
scripts/domain/          日程、行动、工作、事件、考试、关系、结局
scripts/infrastructure/  配置、内容加载、存档、随机数、条件
scripts/ui/              界面与主题
tests/                   自动化测试
```

### 开发约定

- 规则写在 `scripts/domain/`，UI 不直接改持久化状态  
- 新职业 / 事件 / 结局优先加 `data/` 下的 JSON  
- `.godot/`、`builds/` 等本地目录不入库  

### 导出与发版（摘要）

项目含 macOS / Windows / Android 导出预设。发布新安装包时：跑测试 → 改 `export_presets.cfg` 版本号 → 导出并签名 → 更新 CHANGELOG → 打 tag → 在 Releases 上传附件。  
仅同步源码时提交并 `git push` 即可，不必每次都发安装包。详细步骤见历史 CHANGELOG / 维护者备注。
